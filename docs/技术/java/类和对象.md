### final修饰的

1. 变量无法重新赋值，如果是参数，无法被修改
2. 方法无法被重写
3. 类无法被继承
   1. 比如String类，设计成final的原因
      1. 线程安全
      2. 实现字符串常量池
      3. hashcode的不可变性

### 方法重写

1. final不允许重写
2. [static](https://javabetter.cn/oo/static.html) 的，也不允许重写，因为静态方法可用于父类以及子类的所有实例。
3. 不能使用更严格的修饰符
4. 子类不能抛出更高级别的异常
