# 安那般那数息法

## 《佛说大安般守意经》中的呼吸法

### 静坐的时候

把注意力放在呼吸上，也就是两个鼻孔出气的地方，叫做风门

发现注意力跑掉了，就开始数息。吸气数一，呼气数二，三，四。。。这样循环一直到10，再重新从一开始数，直到注意力一直安住在风门

### 好处

1. 放下杂念
2. 注意力放在风门，锻炼专注

### 现实中做事

1. 放下不好的杂念
2. 专注在当下要做的事情，使心不乱

## 南怀瑾的方法

呼吸有四段：吸气、**停顿**、呼气、**停顿**，这个停顿就是息，指的是休息

### 数

我们关注在呼气之后停顿的息上，这样算一次，数到10就重新从1开始

### 随

知道这个息的长短、冷热等，随着这个息

### 止

这个息，更容易让我们感受到空性，也就是宇宙的真理。换一种世俗的说法的话，就是降低大脑频率，降低MDN（预设网络模式），深度休息放松
