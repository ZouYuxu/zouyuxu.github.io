# 记录想法

#### 方法

记录每个起心动念，好的想法和不好的想法都随时记录下来

坚持几个月就可以获得技能，念动即觉

#### 好处

1. 减少自己重复的无意义思考
2. 减少负面想法
3. （其他隐藏好处，留待自己发现... 小提示：谁在思考？)

#### 相关

把各种妄念逐一的清除掉，恢复婴儿时的单纯。——曾仕强
